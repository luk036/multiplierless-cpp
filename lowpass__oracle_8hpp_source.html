18// Modified from CVX code by Almir Mutapcic in 2006.
19// Adapted in 2010 for impulse response peak-minimization by convex iteration by
20// Christine Law.
21//
22// "FIR Filter Design via Spectral Factorization and Convex Optimization"
23// by S.-P. Wu, S. Boyd, and L. Vandenberghe
24//
25// Designs an FIR lowpass filter using spectral factorization method with
26// constraint on maximum passband ripple and stopband attenuation:
27//
28// minimize max |H(w)| for w in stopband
29// s.t. 1/delta <= |H(w)| <= delta for w in passband
30//
31// We change variables via spectral factorization method and get:
32//
33// minimize max R(w) for w in stopband
34// s.t. (1/delta)**2 <= R(w) <= delta**2 for w in passband
35// R(w) >= 0 for all w
36//
37// where R(w) is squared magnitude frequency response
38// (and Fourier transform of autocorrelation coefficients r).
39// Variables are coeffients r and G = hh' where h is impulse response.
40// delta is allowed passband ripple.
41// This is a convex problem (can be formulated as an SDP after sampling).
42
