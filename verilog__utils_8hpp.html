auto csd_coeffs_to_fixed ( const std::vector< std::string > & csd_list) ->FixedCoefficients

Right-align fractional CSD digits so every tap shares one scale.

Each returned string represents round(value * 2**scale_power), where scale_power is the common fractional width.

◆ fix_direct_verilog()

auto fix_direct_verilog ( std::string verilog,
const std::vector< std::string > & port_names )->std::string

Repair csdigit's direct-form module so it compiles.

csdigit emits a trailing comma after the last port and redeclares each output as wire signed ... hN = ..., which conflicts with the port declaration. This removes the trailing comma and turns those output redeclarations into continuous assignments.

Parameters
[in]verilogModule text produced by csd::generate_csd_multipliers().
[in]port_namesOutput port names (h0, h1, ...).
Returns
The repaired module text.
